# Entorno Virtual Python

Proyecto con configuración básica de entorno virtual en Python y control de versiones con Git.

## Requisitos
- Python 3.10+ (o versión instalada)

## Configuración del Entorno Virtual

### En Windows (PowerShell)
```powershell
# Activar entorno virtual
.\.venv\Scripts\Activate.ps1
```

### En Windows (CMD)
```cmd
# Activar entorno virtual
.venv\Scripts\activate.bat
```

### Desactivar entorno
```powershell
deactivate
```
